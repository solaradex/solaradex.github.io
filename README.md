# Marketly Tech

Marketly Tech is a static affiliate storefront for curated electronics, PCs, laptops, gaming gear, PC accessories, and refurbished phones.

## Public site
https://solaradex.github.io/

## Affiliate setup
Product objects in `index.html` include an `affiliateUrl` field. Replace the empty value with an approved affiliate deep link after joining a merchant program.

The site includes an affiliate disclosure and does not process checkout, payment, shipping, returns, or customer service.

## Categories
- Desktop PCs
- Laptops
- Gaming
- Refurbished Phones
- PC Accessories
- Audio

## GitHub Pages
This repository is designed to publish the root `index.html` from `main`.
